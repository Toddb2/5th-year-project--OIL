# Literature

The references this project uses, grouped by topic. Taken from the dissertation draft's bibliography
(Oct 2026) and the papers cited in the code and docs. Entries marked **check** need their details
confirming against the paper before they go in the dissertation.

To find them in the library: search the title in [Discovery](https://discovery.hw.ac.uk/), or use the
Google Scholar link next to each entry. In Scholar, Settings → Library links → add Heriot-Watt, and a
"Find it @ Heriot-Watt" link appears next to results the library holds.
